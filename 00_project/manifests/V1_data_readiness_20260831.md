# PVCarbon V1.0 数据就绪度检查

检查时间：2026-08-31  
结论：可以开始数据预处理和方法联调，不能开始正式因果估计、iLUC碳排放核算或减排抵消率计算。

## 已具备

- 主PV Shapefile：30,023条记录，DBF与SHX记录数一致；
- CLCD：2000–2025年共26期；
- 候选省市县边界：ZIP流校验通过，6套图层组件齐全，省/市/县面分别34、375、2,891条；
- WorldPop：2021、2022年完整；
- IPCC土地与碳核算参数文件：已下载；
- 国家能源局光伏统计原始网页：2015–2022年已保存；
- 生态环境部电网基准资料：2006–2019年区域基准文件和2021年平均因子已保存。

## 未冻结或下载中

- 候选县界只有`name`与`gb`字段，缺少权威来源元数据、历史有效期、上级代码及2010–2022行政区划变更表；
- ERA5-Land：2,057/2,268个预期月变量文件，另有2个partial，仍在下载；
- SoilGrids：中国分块41/252，仍在下载；
- ESA CCI Biomass v7：中国瓦片尚未开始；
- Site/Phase聚合阈值和人工验证样本尚未建立；
- 场址外新增耕地人工验证样本尚未建立；
- Phase年度容量/发电量尚未构建；
- 2020–2022连续一致的正式区域边际电网排放因子尚未获得。

## 允许启动的工作

1. PV属性、日期、重复图斑和几何基础审核；
2. Patch到Site到Phase的候选阈值测试；
3. PV与CLCD投影、像元和年度对齐；
4. 使用候选县界进行静态叠加和代码清洗的流程联调；
5. 设计Phase阈值及土地变化分层人工验证样本。

## 暂不允许启动的正式结果

1. 将场址外新增耕地解释为因果iLUC；
2. 发布县域iLUC排放吨数；
3. 发布光伏减排抵消率；
4. 发布县域iLUC峰值年或碳回收年。
