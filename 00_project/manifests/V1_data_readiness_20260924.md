## 可实现方案：按能否自动化分三层

### 第一层 —— 纯下载/解析，现在就能推进，不卡人

1. **CCD 解压 + 覆盖审计**（P0X 新卡）：archive 已验证，解压 672 个 TIFF，逐省核对是否落在预期
   28 个主要农业省级区域，缺省地区（北京/青海/西藏/台湾/香港/澳门）编 `coverage_missing`。
2. **ERA5-Land 冻结审计**：确认最终变量集与年份范围，核对 2,267 个文件命名与内容，出正式冻结记录。
3. **SoilGrids 冻结**：mean 层直接可用；决定是否补 5%/95% 分位数（V1 要求 Monte Carlo 不确定性，
   迟早要补，可先冻结 mean 支持候选统计）。
4. **MEE 电网因子 PDF → 数值表**：解析 2006–2019 区域基准 + 2021 平均因子的 PDF 表格。
5. **NEA 光伏统计 HTML → 省—年结构化表**：解析 8 个年度网页，供面积—容量校准。
6. **ESA CCI Biomass 下载**：纯下载任务，CEDA 或官方渠道，参照 SoilGrids 的下载脚本模式。
7. **DEM 下载**：选 SRTM 30m 或 Copernicus GLO-30（建议后者，更新、无空洞），纯下载。

以上 7 项**互不依赖、可并行**，全部是 Codex 可执行的下载/解析/审计任务，不需要等任何人工判读，
建议按此顺序起草任务卡，两三周内可以清完。

### 第二层 —— 需要先决策，决策后仍是自动化工作

8. **S06 县界**：需要你选来源（见上次讨论 4 个选项 + 建议），选完是脚本化获取 + 校验。
9. **S13 农业排放边界**：需要 Claude Code + 你先定义 `Agrco2` 系统边界（新增耕地上的化肥/N2O/
   机械排放，还是相对反事实的差值），定完才知道要下载什么参数。
