## 卡片（Claude Code）

### 1. 目标（一句话）

冻结分析网格（= CLCD 原生 Albers 网格），并对 PV 图斑层与候选县界层做只读结构审计，
产出可被 P02–P04 直接引用的 `frozen_sources.tsv` + `patches_clean.gpkg` + 审计报告；
凡不满足门槛的项目**停下报告**，不自行修补原始文件。

### 3. 步骤（有序、无歧义）

**A. 冻结分析网格**

1. 读任一 CLCD `.tif` 的 GeoTIFF 键，写出完整网格定义：CRS WKT/PROJ、pixel size、
   左上角原点、行列数、范围、NoData、数据类型、类别值域。
2. 逐幅核对 26 幅 CLCD：同一 CRS / transform / 尺寸 / NoData；类别值域一致；可读；
   与 `checksums/` 比对 SHA-256。
3. 把网格定义写成机器可读 `analysis_grid.json`（proj4 + 6 参数 transform + width/height +
   nodata），P02 之后所有栅格化/相交都引用它。

**B. PV 图斑层审计（只读）**

4. 读 shp：记录数、几何类型、CRS、bbox、空/无效几何数（`is_valid`）、自相交、
   重复几何（几何哈希）、多部件面数、面积字段单位核验（`PV_Area` vs 重投影 Albers 后
   计算面积的比值分布 → 确认单位为 km²）。
5. `Inst_year` 分布（期望 2010–2022，无空）；`Inst_time` 解析为 YYYYMMDD，列出所有
   非法/与 `Inst_year` 不一致的记录（已知 3 条：`OBJECTID` 21400 / 20046 / 20048）。
6. `Major_type` 取值分布（期望 7 类）；标记 `Ocean area`（95 面）。
7. **派生层**（不改原始）：`patches_clean.gpkg`，字段
   `patch_id`（`P` + 6 位，按 `(round(Lon,6), round(Lat,6), OBJECTID)` 排序编号）、
   `objectid`、`inst_year`、`inst_date`（修正后 YYYYMMDD；3 条异常按下方参数处理）、
   `inst_date_flag`（`ok` / `fixed_month` / `year_from_time` / `time_from_year`）、
   `major_type`、`pv_area_km2_src`、`pv_area_m2_albers`（重投影后计算）、
   `n_parts`、`geom_fixed`（bool），几何为 `make_valid` 后的 Albers 面。
8. 审计报告 `pv_patch_audit.md` + `pv_patch_audit.json`。

**C. 候选县界审计（只读，pilot 标注）**

9. 对每个候选县界层：要素数、CRS、bbox、字段清单、几何有效性、拓扑重叠/空隙抽查、
   编码字段（`gb`/`code`）位数与前导零、与 GB/T 2260 县级代码规则的符合度。
10. 报告 `boundary_candidates_audit.md`：明确写出**缺**权威来源元数据、历史有效期、
    上级代码、2010–2022 变更表 —— 即"仅可试算"。

**D. 汇总**

11. 写 `metadata/frozen_sources.tsv`：每个源一行，列
    `source_id, name, path, version, sha256_or_manifest, crs, resolution, record_count,
    frozen(yes/pilot/no), notes`。PV = `frozen: yes`（若 B 全过）；CLCD 网格 = `frozen: yes`；
    候选县界 = `frozen: pilot`。
12. 同步更新 `metadata/source_status.tsv`（S01 → `AVAILABLE_FROZEN` 若通过；S02 → 同）
    与 `metadata/tasks.tsv` T01 的 `status`。

### 4. 参数（具体值 / 显式网格，不留空）

- 分析网格 = CLCD v01 原生网格。`analysis_grid.json` 由步骤 A 从 CLCD 文件读出，
  **不得手填**；预期 `+proj=aea +lat_1=25 +lat_2=47 +lat_0=0 +lon_0=105 +x_0=0 +y_0=0
  +datum=WGS84 +units=m`，30 m，原点 (X=-2629624.783, Y=5924251.560)，尺寸 161378×135079。
- 面积单位判定阈值：`median(pv_area_km2_src / (pv_area_m2_albers/1e6))` ∈ [0.9, 1.1] → 判为 km²；
  否则 **BLOCKED**。
- 3 条日期异常的**派生层**处理（原始不改）：
  - `OBJECTID=21400`：`Inst_time=201650831` 非法 → `inst_date` 置该记录 `Inst_year` 的
    年份 + `0701`（年中占位），`inst_date_flag=year_from_time`。
  - `OBJECTID=20046`：`Inst_time=20170721` vs `Inst_year=2018` → 以 **`Inst_time` 为准**
    改 `inst_year=2017`，`flag=year_from_time`。
  - `OBJECTID=20048`：`Inst_time=20190321` vs `Inst_year=2018` → 以 **`Inst_time` 为准**
    改 `inst_year=2019`，`flag=year_from_time`。
  - 若 Codex 判断"以 Inst_time 为准"不合理（例如 Inst_time 明显更可疑）→ **BLOCKED**，
    在运行记录里给出两条记录的几何位置、邻近 patch 的年份分布，交 Claude Code 定夺。
- `patch_id` 排序键：`(round(Lon,6), round(Lat,6), OBJECTID)` 升序，保证重跑一致。
- 几何清洗：`shapely.make_valid`；面积为 0 或 `is_empty` 的面 → 保留记录但
  `geom_fixed=true` 且 `pv_area_m2_albers` 记 0，列入审计报告，不删。

### 6. 验收门槛（可判定）

- [ ] `patches_clean.gpkg` 记录数 = 30,023；`patch_id` 唯一；CRS = analysis_grid。
- [ ] `Σ pv_area_m2_albers` 与源 `Σ PV_Area`×1e6 的相对差 < 2%（单位与几何一致性）。
- [ ] `Inst_time` 非法/不一致记录数 = 3，且均已按参数处理并打 flag。
- [ ] 26 幅 CLCD：CRS/transform/尺寸/NoData 全一致；SHA-256 全部与 `checksums/` 匹配。
- [ ] `analysis_grid.json` 的 proj/transform/尺寸与 CLCD 文件读出值逐字节一致。
- [ ] 候选县界审计明确标注 `frozen: pilot` 并列出 4 项缺失。
- [ ] `frozen_sources.tsv` 覆盖 PV / CLCD网格 / 候选县界三行；`source_status.tsv`、
      `tasks.tsv` T01 已同步。

### 7. 失败即停（写进运行记录的 BLOCKED，不要自行解决）

- CLCD 任一幅 CRS/尺寸/NoData 与其余不一致，或 SHA-256 不匹配。
- 面积单位判定比值落在 [0.9,1.1] 之外。
- `Inst_time` 异常记录数 ≠ 3（说明还有未知异常）。
- 几何 `make_valid` 后仍有拓扑错误影响面积 > 0.1% 的面。
- 服务器 GIS 环境（`code/env/`）不可用。
