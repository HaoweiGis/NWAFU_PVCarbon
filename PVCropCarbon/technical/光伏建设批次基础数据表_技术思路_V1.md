## 1. 目标与术语边界

把陈月红光伏图斑（Patch）转换为可复现、可审核的**建设批次（Phase）矢量**，作为后续
作物退出、场址外环带土地变化与碳核算的**空间—时间骨架**。

本表**只做空间聚合与时间分组**，不做任何土地利用变化判断。允许表述："光伏图斑"、
"场址（Site）"、"建设批次（Phase）"、"建设前主要地类（源自带）"。禁止在本阶段使用
"诱发新增耕地 / iLUC / 有效耕地损失"——这些须待反事实识别（P08）通过。

## 4. Patch 层预处理（P01）

1. **稳定编号**：按 `(Lon, Lat, OBJECTID)` 升序编 `patch_id = P000000…`，保证重跑逐字节一致。
2. **几何有效性**：`shapely.make_valid` 修复 **144 个**源无效几何（自相交等）。
3. **完全重复几何**：检出 **43 组（87 个图斑）**几何与全部属性完全一致，判为数字化重复
   （源数据 ArcGIS Append/SpatialJoin 血缘所致）。每组保留 `patch_id` 最小者，**去 44 个**，
   被去图斑记入 `outputs/audits/p01_duplicate_patches.csv`。→ 派生图斑层 **29,979** 个。
4. **面积单位确认**：重投影 Albers 后计算面积，与源 `PV_Area` 的比值中位数 = **1.0000**，
   确认 `PV_Area` 单位为 **km²**（Σ 均为 3,711 km²）。
5. **建设日期**：`Inst_time` 解析为 `YYYYMMDD`；**3 条异常**在派生层修正（不改原始 shapefile）：

   | OBJECTID | 现象 | 处理 | flag |
   |---|---|---|---|
   | 21400 | `Inst_time=201650831`（月份非法） | 用 `Inst_year`（2016）+ `0701` 年中占位 | `fixed_missing` |
   | 20046 | `Inst_time=20170721` 与 `Inst_year=2018` 不符 | 以 `Inst_time` 为准，改建设年 2017 | `year_from_time` |
   | 20048 | `Inst_time=20190321` 与 `Inst_year=2018` 不符 | 以 `Inst_time` 为准，改建设年 2019 | `year_from_time` |

6. **多部件**：127 个 `MultiPolygon`，记 `n_parts`；距离判定按部件展开。
7. **海上光伏**：95 面 `Major_type=Ocean area`，保留并标 `is_offshore`（可能无所属县）。

## 5. Patch → Site：空间聚合（P02）

### 5.1 定义

**Site = 图斑之间"边界最短距离 ≤ 邻接阈值 d"关系的连通分量。**

即：以图斑为节点，任意两图斑外环边界间平面距离（Albers）≤ d 则连边（相接记距离 0），
连通分量即一个 Site。Site **跨建设年、跨行政边界**聚合——先构造完整 Site / 完整 Phase，
再与县界相交，不先按县裁碎图斑。

### 5.2 算法

1. 每个图斑缓冲 d，与原始图斑层做 `intersects` 空间连接得到边集（边界距离 ≤ d 的图斑对）。
2. `scipy.sparse.csgraph.connected_components` 求连通分量。
3. `site_id = S{d:03d}_{seq:06d}`，`seq` 按分量最小成员位置排序，保证确定性。

5 个候选邻接阈值 **30 / 50 / 100 / 200 / 300 m** 全部产出（`work/site_membership.parquet`，
`patch_id × site_threshold_m → site_id`，149,895 行）。

### 5.3 巨型 Site（连片光伏基地）

诊断（`outputs/audits/p02_site_diagnostics.json`）：

| 阈值 m | Site 数 | 单图斑 Site 占比 | 最大 Site 图斑数 | hull 面积 p99 / max (km²) | span max (km) | Site 跨 ≥5 建设年 | hull>50 km² |
|---|---|---|---|---|---|---|---|
| 30 | 24,560 | 85.4% | 21 | 2.5 / 21.8 | 10.8 | 7 | 0 |
| 50 | 18,273 | 71.0% | 34 | 3.2 / 21.8 | 10.9 | 66 | 0 |
| **100** | **12,590** | **58.6%** | **77** | **4.8 / 29.0** | **10.9** | **213** | **0** |

| 300 | 8,160 | 51.3% | 140 | 8.1 / 102.6 | 19.5 | 397 | 2 |

## 6. 邻接阈值选择规则（R1–R6，S07 前的临时决策）

Site 聚合有两类相反误差：

- **过碎**（阈值偏小）：单一物理电站被内部检修道、升压站间隙切成多个 Site；
- **过并**（阈值偏大）：相邻的独立电站被桥接为一个 Site，其"场内"吸收邻厂面积、压缩场址外环带。

对每个候选阈值按下列规则打分，取**同时通过 R1 与 R2、且落在边际合并拐点之内**者：

| 规则 | 判据 | 30 | 50 | **100** | 200 | 300 |
|---|---|---|---|---|---|---|
| **R1 拒过碎** | 单图斑 Site 占比 < 65%（卫星数字化的地面电站通常含多个图斑碎片） | 85% ✗ | 71% ✗ | **59% ✓** | 53% ✓ | 51% ✓ |
| **R2 拒过并** | 无 hull>50 km² 巨型 Site，且 hull p99 ≲ 5 km²（≈500 MW 单厂上限） | ✓ 2.5 | ✓ 3.2 | **✓ 4.8** | △ 6.6 | ✗ 2 个 / 8.1 |
| **R3 边际拐点** | Site 数逐步降幅 −26% / −31% / −26% / −12%；降幅骤减且伴随过并即已过拐点 | — | — | **拐点内** | 拐点内 | 过拐点 ✗ |
| **R4 稳健** | 主阈值居中，相邻两候选可直接作敏感性区间 | 边缘 | 下界 | **居中** | 上界 | 边缘 |
| **R5 惯例** | 光伏场址聚合常用 ≈100 m；方法节可解释的整数 | | | **✓** | | |
| 佐证 | 最大 Site 图斑数（单厂物理上限） | 21 | 34 | 77 | 138 △ | 140 |
| 佐证 | Site 跨 ≥5 建设年数（大型分期基地可信，过多=并入邻厂） | 7 | 66 | 213 | 335 △ | 397 |

**结论**：

- 30 / 50 m **过碎**——71–85% 的 Site 只含 1 个图斑，说明单厂被切碎；
- 200 m 出现**过并苗头**（hull p99 6.6 km²、最大 Site 138 图斑、335 个 Site 跨 ≥5 年）；
- 300 m **明确过并**（2 个巨型 Site、span 19.5 km、Site 数降幅骤减到 12%）；
- **只有 100 m 同时通过 R1 + R2 + R3**，且正处"重连碎片"到"桥接邻厂"的过渡带中间。

**临时基线 = 100 m**；主敏感性 = **50 / 200 m**（V1 设计要求报区间）；30 / 300 m 仅作极端边界附录。
下游属性统计先基于 `phases_d100.shp`。

**R6 覆盖条款**：S07 分层高分影像样本到位后**重新选择**——主阈值取算法"同场址"标签与
人工判读标签一致性（F1 / Cohen κ）最高的阈值；若指向 50 m，则切换并重跑下游，全程记录。
在此之前 100 m 是工作默认，**不是冻结值**。

## 7. Site → Phase：时间分组（P03）

**Phase（建设批次）= (site_id, 修正后建设年份)。** `phase_id = <site_id>_<year>`
（如 `S100_000042_2016`）。

- 几何 = 该批次全部图斑的并集（`unary_union`），不做简化或缓冲；
- 同一 Site 同一年在空间上分成数块 → 仍为**一个 Phase**（多部件几何，`n_parts>1`）；
- 精确 `Inst_time`（`date_min` / `date_max`）随批次保留，供后续建设前 / 建设后年份窗口使用。

### 7.1 数据组织（三级结构）

```
图斑 Patch ──空间聚合(阈值)──▶ 场址 Site ──按建设年拆分──▶ 建设批次 Phase
29,979 个                      12,590 个 (100 m)            18,059 个 (100 m)
(不随阈值变)                     一个物理电站                  = (Site, 建设年)
```

- 一个 **Site** 若分多年建设，就拆成多个 **Phase**：14 个图斑、跨 5 个建设年的一个场址
  → 5 个 Phase（共用 `site_id`，`phase_id` / `year` 不同）。
- `phases_d{d}.shp` 是**一张表**：**1 行 = 1 个 Phase**，**16 列 = 16 个属性**（每个 Phase 都有这 16 个值）。
  字段是"列/属性种类"，不是"每个字段对应一个 Phase"。
- `site_ny`（Site 跨建设年数）、`site_np`（Site 图斑总数）是把 Site 级信息**冗余**写到每个 Phase 行上，
  方便直接筛选；要回到 Site 层就按 `site_id` 分组。

各阈值数量（图斑恒 29,979）：

| 阈值 | Site 数 | Phase 数（= shp 行数） |
|---|---|---|
| 30 m | 24,560 | 26,688 |
| 50 m | 18,273 | 22,414 |
| **100 m（基线）** | **12,590** | **18,059** |
| 200 m | 9,288 | 15,154 |
| 300 m | 8,160 | 14,048 |

100 m 下 18,059 = 9,270 个单年建成 Site（各 1 Phase）+ 3,320 个多年建成 Site（各 2–9 Phase）。

**质量门槛（均通过）**：每个阈值 Σ`patch_cnt` = 29,979；`phase_id` 唯一；
`area_m2 ≤ parea_sum`；`overlap_r > 5%` 的 Phase 仅 1 个（真实部分重叠图斑，非重复几何）；
Σ`area_m2` 阈值间差 < 1%（恒 3,711 km²）；`year` 全部 ∈ [2010, 2022]。

产物：`work/phases.gpkg`（layers `phases_d30/50/100/200/300`）、
`outputs/phase_vector/phases_d{d}.shp`（下游按 `phase_id` 左连接添加属性）。

## 8. `phases_d{d}.shp` 字段字典

- **坐标系**：分析 Albers（§3）。`.prj` 中 PROJCS 名为 `unknown`（proj4 无名称），
  但椭球 / 投影参数（`aea` 25/47/105，WGS84）正确；`.cpg` = UTF-8。
- **粒度**：一行 = 一个建设批次 Phase。**主键 `phase_id`（全表唯一）**。
- Shapefile 字段名上限 10 字符，均已满足。

| 字段 | 类型 | 单位 | 含义 | 说明 / 取值 |
|---|---|---|---|---|
| `phase_id` | 文本 | — | **建设批次唯一编号**，下游 join 主键 | = `<site_id>_<year>`，如 `S100_000042_2016`；全表唯一、无重复 |
| `site_id` | 文本 | — | 场址编号 | = `S{阈值:03d}_{序号:06d}`（如 `S100_000042`）。同一 Site 分多年建设时**多行共用**，用 `year` / `phase_id` 区分（本层 12,590 个 Site、18,059 行） |
| `thr_m` | 整数 | m | 生成本层所用的 Patch→Site 邻接阈值 | 本层恒 `100` |
| `year` | 整数 | 年 | 建设年份 | 2010–2022；P01 修正后的 `inst_year`（3 条日期异常见 §4） |
| `patch_cnt` | 整数 | 个 | 本批次包含的原始图斑数 | 去重后口径；全表 Σ = 29,979 |
| `area_m2` | 浮点 | m² | **本批次占地面积**（图斑并集面积，Albers 等积） | 计算真实占地、暴露面积、密度用此字段 |
| `parea_sum` | 浮点 | m² | 本批次各图斑面积之和 | 与 `area_m2` 之差 = 图斑间重叠 + 内部缝隙被并集消除的量 |
| `overlap_r` | 浮点 | 比例 | 图斑重叠度 = 1 − `area_m2` / `parea_sum` | ∈ [0, 1)；≈0 为正常；本层仅 1 个批次 > 0.05（真实部分重叠图斑） |
| `n_parts` | 整数 | 个 | 本批次并集几何的多边形部件数 | > 1 = 同 Site 同年在空间上分成几块建设 |
| `date_min` | 文本 | YYYYMMDD | 批次内最早图斑安装日期 | 来自源 `Inst_time` |
| `date_max` | 文本 | YYYYMMDD | 批次内最晚图斑安装日期 | `date_min`≠`date_max` 表示同年跨月建设；供后续建设前 / 建设后年份窗口的"第 0 年"判定 |
| `mtype_mode` | 文本 | — | 本批次**按面积加权**的主导建设前地类 | 取值：`Cropland` / `Grassland` / `Woodland` / `Unused land` / `Built-up land` / `Water surface` / `Ocean area`（源 `Major_type`，非本研究独立判定） |
| `mtype_crop` | 浮点 | 比例 | 本批次建设前地类为 `Cropland` 的面积占比 | ∈ [0, 1]；= 0 表示批次内无耕地图斑 |
| `offshore` | 布尔 | — | 本批次是否含 `Major_type = Ocean area` 的图斑 | `T`/`F`（GIS 中或显示为 1/0）；海上光伏，Phase×县相交时可能无所属县 |
| `site_np` | 整数 | 个 | 本批次**所属 Site**（跨全部年份）的图斑总数 | 是 Site 级属性，非本批次的图斑数（那是 `patch_cnt`） |
| `site_ny` | 整数 | 个 | 本批次所属 Site 跨的建设年数 | = 该 `site_id` 在本层出现的行数。`= 1` → `site_id` 不重复；`> 1` → `site_id` 多行共用 |

> `geometry` 为 Phase 的图斑并集面（可能是 MultiPolygon，见 `n_parts`）。

## 9. Phase → 县相交：T01 表（P04，待 S06）

- **先构造完整 Phase，再与权威县界做 `intersection` 叠加**；跨县 Phase **不**按县分片缓冲。
- **表粒度：一行 = 一个 `phase_county`**（Phase × 县）。Phase 全在一个县内 → 1 行；
  跨 n 个县 → n 行，`phase_id` 各行相同，`phase_county_id` 不同。
- 每行附：`intersection_area_m2`（该县相交面积）、`intersection_pct`（= 相交面积 / 完整
  `phase_area`，同一 `phase_id` 各行之和 = 1）、`is_primary_county`（相交面积最大的县 = true，
  供需要单县汇总时使用，不改变跨县多行粒度）。
- `city_id` / `province_id` 由 `county_id` 经行政层级 crosswalk 派生，**不做单独空间相交**
  （避免嵌套边界碎片错配）；全部为字符串，保留前导零。
- 核对门槛：Σ 各县 `intersection_area_m2` = 完整 `phase_area`（容差内）；落在任何县界外的
  面积记 `unassigned_area_m2`，不静默丢弃。

**阻塞（S06）**：权威县—市—省边界、稳定行政区划代码、2010–2022 行政区划变更对照表尚未到位。
现有候选边界（省 / 市 / 县 = 34 / 375 / 2,891，仅 `name` / `gb` 字段）只能用于流程试算，
不能产出正式县代码列。

## 10. 已知局限

1. **无地面真值**：Site 邻接阈值最终须由 S07 分层高分影像人工样本确定；当前 100 m 为临时基线。
2. **远距离 2 图斑 Site**：30 m 阈值下已存在 span 达 10.8 km、hull 达 21.8 km² 的 2 图斑 Site
   （多在青海塔拉滩、内蒙古等连片基地）；是否为误并须 S07 逐一核对。
3. **建设年精度**：`Inst_time` 来自影像首见年，可能滞后实际开工；建设年精度约 ±1 年。
4. **`Major_type` 为源自带**的"建设前主要地类"，非本研究独立判定的土地覆盖，仅作辅助分层。
5. **无容量 / 发电量**：装机与发电量须另行由国家能源局省级统计 + 面积—容量模型补齐（D12–D13，
   不属本表）。
6. 完全重复几何去重（44 个）改变了"全部图斑进入"的口径为"全部**去重后**图斑进入"。
