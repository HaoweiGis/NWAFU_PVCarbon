# NWAFU_PVCarbon 项目目录

- `CURRENT_V1.md`：当前唯一有效版本入口；
- `researchwrite/versions/v1/`：V1研究设计、数据需求、QA与导出文件；
- `data_sources/`：本地原始数据压缩包，按数据主题存放；
- `references/`：论文、来源笔记和截图；
- `scripts/`：服务器准备与下载脚本；
- `00_project/manifests/`：目录整理和文件校验记录。

新增版本时使用 `researchwrite/versions/v2/` 等独立目录，不将多个版本文件平铺在项目根目录。
早期且容易误导的技术路线已经登记后删除，不在项目中继续保留可被误用的副本。
