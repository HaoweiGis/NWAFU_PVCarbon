# Style guide

- Language: Chinese, formulas and field names may use English symbols.
- Tone: scientific-question-driven and conservative.
- Required terminology: 引致新增耕地, 责任县, 属地县, iLUC排放, 抵消率, 峰值年, 碳回收年.
- Forbidden expressions: 县域碳中和, 已证明诱发, 所有新增耕地, 实现达峰, unless the defined evidence and system boundary support them.
- Distinguish: observed / causally attributed / projected / scenario-based.
- Report uncertainty intervals with every county carbon and payback estimate.
