# PVCarbon V1：最小必要数据与下载方案

版本：V1.0-minimal  
日期：2026-08-31  
用途：只服务县域归因iLUC排放、光伏减排抵消率和iLUC碳回收，不扩展作物产量、选址或县域整体碳中和。

## 1. 最小数据链

### A. 土地压力与因果识别

1. PV图斑与建设年份，2010–2022；
2. CLCD年度土地覆盖，2000–2025；
3. 权威县界、稳定县代码和行政区划变更表；
4. Site/Phase阈值人工样本与土地变化验证样本；
5. 最小县域时变控制：ERA5气候、WorldPop人口、CLCD建设用地扩张。

### B. iLUC碳排放

1. SoilGrids SOC、容重、砾石率，0–5、5–15、15–30 cm；
2. ESA CCI Biomass v7 AGB与AGB标准差，中国范围，2010–2012及2015–2022；
3. IPCC根冠比、碳分数、土地转化和释放时间参数。

### C. 光伏毛减排收益

1. Phase或县域年度PV发电量；若缺失，则由面积—容量模型和辐射模型估算；
2. 国家能源局省级年度集中式PV装机容量，用于面积—容量校准；
3. ERA5-Land太阳辐射、气温及PV系统性能参数；
4. 官方区域电网OM作为主情景，官方平均因子作为标注清楚的敏感性情景。

## 2. 停止下载的数据

- GADM和更多非权威县界：仅试跑，不能解决正式县代码问题；
- WRI全球电厂库：不能替代中国Phase容量或发电量；
- 作物分布、产量、复种指数；
- CACD；
- DEM、道路、保护地、电网接入和选址成本，除非后续异质性分析明确需要；
- 2023年以后情景数据，直至观测期结果成立。

## 3. 串行下载顺序

### 第1段：小文件和控制变量

- WorldPop 2021–2022 1 km栅格（已完成，不再扩展历史年份）；
- IPCC 2019 Refinement Vol.4第2–7章及根冠比表；
- 生态环境部2006–2019区域电网OM/BM；
- 2021–2022官方平均电力排放因子及原始HTML。
- 国家能源局2015–2022光伏建设运行原始网页；2010–2014另行核验后补齐。

### 第2段：土壤碳

- SoilGrids三项变量、三层深度、中国范围分块；
- 先下载mean形成基线，再决定是否补5%和95%分位数；
- 每个文件必须通过TIFF检查，统一网格后再计算0–30 cm SOC库存。

### 第3段：植被碳

- ESA CCI Biomass v7中国相交瓦片；
- AGB和AGB标准差同步下载；
- 按CEDA MD5逐文件验证；
- BGB由AGB乘土地类型对应根冠比估算，不把AGB直接称为总生物量。

## 4. PV发电量的独立收集路径

1. 保存国家能源局2010–2022年度光伏建设运行原始网页或附件；
2. 抽取省、年份、新增集中式装机、累计集中式装机、光伏发电量和利用小时；
3. 将主PV图斑按省—建设年汇总面积；
4. 估计并交叉验证省年面积—容量转换系数；
5. 用ERA5辐射、温度、性能比和衰减率计算Phase年度发电量；
6. 用官方省级/全国发电量和利用小时校准，不把WRI电厂点当作容量真值。

## 5. 电网因子的边界

- 2006–2019官方区域电网OM/BM按发布版本保存；
- 发布年度不等于底层数据年度，必须记录实际统计期；
- 尚无完整官方2020–2022区域OM时，不制造“正式边际因子”；
- 可设置最近可得OM延续、官方平均因子和化石电力因子等敏感性情景；
- 主文必须区分边际因子与平均因子。

## 6. 数据冻结门槛

1. 县界、验证样本和控制集未完成，不称为因果iLUC；
2. SoilGrids、ESA Biomass和参数表未冻结，不报告iLUC吨数；
3. PV发电量和电网因子未冻结，不报告抵消率或碳回收年；
4. 只下载不校验不视为数据可用。
